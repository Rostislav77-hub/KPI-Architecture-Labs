# Лабораторна робота №3: Взаємодія (Sequence)

**Опис:**
Ця лабораторна робота присвячена моделюванню взаємодії між мікросервісами ігрового маркетплейсу для прецеденту UC-01 «Купівля предмета». Побудовано три окремі Sequence-діаграми для різних Gherkin-сценаріїв (успіх, нестача коштів, конкурентний доступ) з урахуванням бази даних (Лаба 1) та вимог до транзакцій (Лаба 2).

**Структура файлів:**
- `spec.md` — специфікація взаємодії та критерії прийняття.
- `sequence.mmd` — сирий код фінальних діаграм.
- `diagrams.md` — відрендерені Sequence-діаграми.
- `DEFENSE.md` — захист архітектурних рішень.
- `adr/0001-payment-topup-in-opt.md` — архітектурне рішення щодо поповнення балансу.
