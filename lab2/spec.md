# Специфікація вимог: Маркетплейс ігрових предметів (Лабораторна 2)

## 1. Актори (Actors)
1. **Player (Людина)** — користувач маркетплейсу, який може виступати у ролі Покупця (Buyer) або Продавця (Seller).
2. **PaymentGateway (Зовнішній сервіс)** — стороння система (наприклад, Stripe), яка обробляє транзакції для поповнення віртуального гаманця гравця.

## 2. Головні цілі (Main Goals)
- Гравець повинен мати можливість поповнити баланс гаманця через зовнішній шлюз.
- Гравець повинен мати можливість виставити предмет зі свого інвентарю на продаж.
- Гравець повинен мати можливість купити виставлений предмет, якщо у нього достатньо коштів на балансі.

## 3. EARS Вимоги
1. **REQ-01:** WHEN the Player wants to buy an item, the system SHALL process the transaction. 
2. **REQ-02:** WHILE the Player is browsing the market, the system SHALL display available items.
3. **REQ-03:** WHEN the Player tops up the wallet, the PaymentGateway SHALL add funds.
4. **REQ-04:** WHERE the skin rarity is "Legendary", the system SHALL highlight it in gold.

## 4. User Stories
- **US-01:** Як Гравець, я хочу купувати предмети на маркеті, щоб покращити свій інвентар.
- **US-02:** Як Гравець, я хочу поповнювати баланс через платіжну систему, щоб мати змогу купувати скіни.
- **US-03:** Як Гравець, я хочу виставляти свої предмети на продаж, щоб заробляти гроші.

## 5. Gherkin Сценарії
**Scenario: Купівля предмета (UC-01)**
Given Гравець вибрав предмет на маркеті
When Гравець натискає "Купити"
Then Предмет додається в інвентар Гравця
And Предмет видаляється з маркету
