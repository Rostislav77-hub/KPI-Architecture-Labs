# Специфікація вимог: Маркетплейс ігрових предметів (Лабораторна 2)

## 1. Актори (Actors)
1. **Player (Людина)** — користувач маркетплейсу, який може виступати у ролі Покупця (Buyer) або Продавця (Seller).
2. **PaymentGateway (Зовнішній сервіс)** — стороння система (наприклад, Stripe), яка обробляє транзакції для поповнення віртуального гаманця гравця.

## 2. Головні цілі (Main Goals)
- Гравець повинен мати можливість поповнити баланс гаманця через зовнішній шлюз.
- Гравець повинен мати можливість виставити предмет зі свого інвентарю на продаж.
- Гравець повинен мати можливість купити виставлений предмет, якщо у нього достатньо коштів на балансі.
