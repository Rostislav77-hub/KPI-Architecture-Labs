# Лабораторна робота №2: Вимоги та Use Cases

## Опис
Ця лабораторна робота присвячена збору та формалізації вимог для ігрового маркетплейсу. Визначено функціональні (EARS) та нефункціональні (NFR) вимоги, описано користувацькі історії (User Stories) та детальні сценарії у форматі Gherkin. Також побудовано Use Case діаграму для візуалізації меж системи.

## Структура файлів
- `spec.md` — специфікація вимог (EARS, User Stories, Gherkin сценарії, Traceability Matrix).
- `use_cases.mmd` — Use Case діаграма у форматі Mermaid.
- `DEFENSE.md` — аудит розбіжностей та обґрунтування архітектурних рішень (ADR).
- `ai/` — історія ітеративної взаємодії з ШІ (аудит та покращення).
