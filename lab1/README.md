# Лабораторна робота №1: Маркетплейс ігрових предметів

## Опис домену
Цей проєкт представляє собою модель даних для торгової площадки ігровими предметами. 
Система дозволяє гравцям зберігати предмети у своєму інвентарі, а також купувати та продавати їх на внутрішньому майданчику.

**Основні концепції бізнес-логіки:**
- У грі існують базові шаблони скінів (вони визначають назву зброї, сам скін та його рідкість).
- Гравці володіють конкретними екземплярами цих скінів (інвентарними предметами), які мають унікальний показник зношеності (`float`).
- Гравці можуть здійснювати транзакції на маркеті: один гравець (продавець) передає предмет іншому (покупцеві) за фіксовану ціну.

## Структура файлів
- `spec.md` — текстова специфікація сутностей, атрибутів та зв'язків.
- `model.mmd` — декларативний код ER-діаграми у форматі Mermaid.
- `DEFENSE.md` — документ для рев'ю (аудит моделі та перевірка критеріїв).
- `ADR-01.md` — архітектурне рішення щодо використання асоціативної сутності.
- `ai/` — історія промптів та первинної генерації моделі.
